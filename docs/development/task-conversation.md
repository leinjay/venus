# 任务对话体验调整（2026-10-23）

依据用户三张真机截图及“语音转文字支持配置中的模型”的补充，先明确本轮行为，再实现。分支沿用 `codex/task-module`。

## 界面与导航

- 对话记录占据主区域，输入栏固定在编辑页底部；编辑时隐藏应用底部 Tab 栏，键盘从输入栏下方弹出，输入栏随键盘安全区域上移。表单与对话仍是一份草稿。
- “整理任务”改为“发送”；发出立即出现用户消息和助手接收状态，按钮切换为“停止”。结束、失败或停止后恢复发送。等待时可输入下一条，不因打字取消上一条。
- 对话顶部仅保留紧凑的模型图标/中文名称入口，点开选择与授权；管理模型跳到真实设置 Tab。设置返回时恢复来源任务页面及输入、草稿和滚动上下文，不在任务导航栈复制设置页面。
- 返回不弹出离开菜单：停止请求、自动保存草稿后返回。保存失败保留本页并说明原因。再次进入自动恢复有效草稿，轻提示恢复结果；统一“保存”仍是任务属性写入与通知安排的唯一提交操作。

## 对话、流式和保存

- 每条任务拥有稳定的本机会话 ID。消息按轮次顺序记录，含时间和完成/停止/失败状态；保存任务不会清除文字对话，重新编辑可继续查看与补充。新任务未保存时跟随新建草稿；七天草稿过期不删除已保存任务的对话。永久删除任务时清理对应对话。
- 旧草稿恢复时保留已有消息；旧的已保存任务此前未保留对话，无法重建，首次重新对话后开始记录。对话仅存手机，不进入 Watch 快照或任务字段历史。
- 远程配置启用流式时逐事件解析 SSE，本机 Qwen 按生成进度更新。界面只显示回复 JSON 顶层 `message` 中的自然语言，隐藏推理、原始协议、属性 JSON 和内部字段。完整响应结束并通过应用校验后才合并属性；停止/失败/配置变化时部分回复标明未完成，不应用部分属性。
- 助手需要简短说明已整理什么、哪些信息缺少，并可询问用户要调整哪里。不谎称已创建/保存任务；未点统一保存时使用“已整理到草稿”。保持现有字段冲突和外部更新保护。
- 设置的非流式配置仍按非流式调用，界面显示等待状态；不为动画伪造分包、不自动换服务。原有凭据、授权、超时和迟到结果保护继续生效。

## 语音转文字与模型能力

- 系统离线语音是一个明确选项，不再是唯一入口。设置增加独立“任务语音转文字”绑定，可选择具备音频转写协议的具名模型；文字聊天和转写选择互不覆盖。
- 首版音频模型接入 `audio/transcriptions` 兼容协议，API 根地址、模型 ID、Key、私网/第三方、超时沿用模型配置。请求为 multipart，返回 JSON `text`。不把 DeepSeek/Qwen 文字模型当成音频模型；没有音频接口的服务不能仅凭聊天成功被选为转写。
- 选择模型录音时只申请麦克风，不申请 Siri/系统语音权限；M4A 录音最多两分钟。远程或局域网转写须针对录音外发单独授权，显示目标；本轮授权例外替代旧“原始录音永不外发”规则，仅影响明确选择的语音转写，文字对话仍不发送音频。
- 转写结束后文字进入输入栏供核对，用户再发送给对话模型。失败/取消保留本机录音与重试/删除入口，不自动切 Siri 或另一服务；录音随草稿保留最多七天，成功插入文字、丢弃或保存任务后清理。不进入对话历史、Watch、普通任务属性或版本记录。
- 系统返回 Siri/Dictation 被禁用时，显示中文原因与“系统设置→通用→键盘→启用听写”指引，也可改选转写模型；应用不能替用户打开系统开关。保留已识别文字，停止/取消不误报失败。
- 本机 Qwen2-VL/WhisperKit 仍没有集成运行库，界面改为明确的“尚未接入运行能力”，不是密钥错误或点击下载即可修复。语音支持已配置音频模型并不代表本机 Whisper 已实现。

## 验证

覆盖 SSE 分片、多字节与转义、仅提取顶层回复、错误及未结束响应、停止不应用属性、旧消息解码、会话归属与保留、转写 multipart/鉴权/错误、能力匹配和独立绑定。云端执行核心测试与 iPhone/Watch 构建；底部输入栏、键盘、录音权限和真实音频服务需手机验收。真实服务测试只使用固定/合成材料，不读取用户任务或录音。

接口依据：[Apple 语音错误码](https://developer.apple.com/documentation/speech/sfspeechrecognitiontask/error)、[Apple 启用听写](https://support.apple.com/guide/iphone/dictate-text-iph2c0651d2/ios)、[音频转写兼容请求](https://developers.openai.com/api/reference/resources/audio/subresources/transcriptions/methods/create)。
